Put your own shaders here.

Files ending in .glsl or .hook in mpv format appear in the renderer's Shaders page
the next time the settings menu is opened. Delete a file to remove it from the list.

Shader packs for mpv, such as Anime4K: unpack the whole archive here. If it has an
input.conf, each chain listed in it becomes one entry in the list.

HLSL shaders from MPC-BE and madVR shaders do not work here.
