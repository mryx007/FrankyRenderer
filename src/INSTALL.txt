FrankyRenderer 1.0.8-native-clsid.1 - Windows x64

DEVELOPER TEST BUILD - NATIVE CLSID INTEGRATION
For player developers testing native FrankyRenderer integration.
Not intended for general use.

Renderer: FrankyRenderer.ax
Renderer CLSID: {B864E92A-1BDF-4DA1-9004-CBF467DF239A}
The MPC Video Renderer compatibility CLSID is not registered or exposed.
A separate internal CLSID is used for the renderer settings page.

Requires a player build with explicit FrankyRenderer integration. Unmodified
player releases may not offer this renderer. Tested on Windows 11 x64.
The registration tools refuse to overwrite another FrankyRenderer installation.
Existing original MPC Video Renderer and madVR registrations are left untouched.

Keep the runtime DLLs and shaders beside FrankyRenderer.ax. Source code,
configuration options and license information are provided at:
https://github.com/mryx007/FrankyRenderer/tree/native-clsid-preview
