FrankyRenderer - video renderer for PotPlayer and MPC-BE (Windows x64)
======================================================================

YOU NEED
  - Windows 11, 64-bit
    (Windows 10 is not supported: it may work, but it is not tested.)
  - PotPlayer 64-bit, Beta 261030 or newer
    (https://t1.daumcdn.net/potplayer/beta/PotPlayerSetup64.exe)
    or MPC-BE 64-bit


INSTALL
  1. Extract the whole ZIP into a folder that stays where it is,
     for example C:\FrankyRenderer.
  2. Close PotPlayer, MPC-BE and MPC-HC.
  3. Right-click Install.cmd and choose "Run as administrator".
  4. In your player, choose "FrankyRenderer" as the video renderer.


UPDATE
  Close the player, copy the new files over the old ones and run
  Install.cmd again (as administrator). Your settings stay.


UNINSTALL
  Right-click Uninstall.cmd and choose "Run as administrator".
  It asks whether your settings should be deleted too.
  Do this before you move or delete the folder.


YOUR SETTINGS
  All settings are kept in one file:
    %APPDATA%\FrankyRenderer\Settings.ini
  In the settings window: Profiles > Settings File > Open shows it.

  Backup Settings.cmd   copies this file into this folder as Settings.ini.
  Import Settings.cmd   uses a Settings.ini from this folder as your settings.

  If this folder is under C:\Program Files, run Backup Settings.cmd
  as administrator. Delete Settings.ini in %APPDATA%\FrankyRenderer
  to start again with the default settings.


FOR PLAYER PACKAGES
  Install.cmd, Uninstall.cmd, Import Settings.cmd and Backup Settings.cmd
  accept /s: no questions and no messages; exit code 0 means success.
  Uninstall.cmd /s keeps the settings.
