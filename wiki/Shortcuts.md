## Everyday examples

Examples from everyday viewing.

| Situation | Setting | What to check |
| --- | --- | --- |
| You want to turn shaders on and off during the movie. | A key for **Disable All Shaders**. | You see the difference immediately. |
| You want Smooth Motion for sports but not for movies. | A key that toggles **Enable Smooth Motion**. | An on-screen message confirms the state. |
| Depending on the movie, you want to switch between bars and a full picture. | A **Next** key for **Zoom Mode**. | Switches between **Fit** and **Fill**. |
| In a bright room, you want to brighten the picture with a key press. | **Increase** and **Decrease** keys for **Gamma**. | Each press changes the value by one step. |
| Playback stutters in demanding scenes. | A key for **Next Quality Preset**. | Ctrl+J shows whether the drops stop. |
| After experimenting with brightness and contrast, you want to go back. | A key for **Reset Picture Controls**. | Only affects the picture controls. |

## Assign a key

Open **Shortcuts**, expand the setting and press a key for the action shown. Depending on the setting, you can toggle it, cycle choices, select a value or change a number in steps. You can also toggle individual shaders. A closed group shows how many shortcuts it has.

Choose a different combination if the player already uses that key. Test with the playback window focused. An on-screen message confirms the action. Only **Ctrl+J** is assigned by default.

## Renderer actions

These shortcuts open statistics, switch off all shaders, select the next quality preset or content profile, reset picture controls or reset statistics.
