## Everyday examples

Examples from everyday viewing. Change one setting at a time and compare the same scene.

| Situation | Setting | What to check |
| --- | --- | --- |
| In a bright living room during the day, the movie looks too dark. | Raise [Gamma](#color-adjustment-picture-controls-gamma) slightly, for example to 1.1. | Brightens the midtones while black stays black. Better than Brightness. |
| Faces look too dark, but black and white are already right. | [Gamma](#color-adjustment-picture-controls-gamma) between 1.05 and 1.15. | Brighter scenes must not look washed out. |
| In the evening, the picture looks cool and bluish. | [Temperature](#color-adjustment-picture-controls-temperature-k) around 5500 K. | White becomes warmer. 6500 K is neutral. |
| An old film has faded colors. | [Saturation](#color-adjustment-picture-controls-saturation) around 1.1. | Skin tones must not turn orange. |
| Black stays slightly gray even though the RGB range is correct. | Lower [Brightness](#color-adjustment-picture-controls-brightness) slightly, for example to -0.02. | Detail in dark clothing should remain. |
| Skin tones have a green or magenta tint. | [Hue](#color-adjustment-picture-controls-hue-degrees) in small steps, for example ±2 degrees. | Check sky and grass afterwards as well. |
| You want to compare quickly with the original. | [Enable Color Adjustment](#color-adjustment-picture-controls-enable-color-adjustment) **Off** and **On** again. | A [shortcut](Shortcuts.md) does this during playback. |

## Picture Controls

Watch for lost detail in black and white when adjusting brightness and contrast. See [Tone Controls](HDR-and-Color-Mapping.md#hdr-color-mapping-tone-controls) for HDR controls by brightness range and [Color Management](Color-Management.md) for display calibration.

| Setting | What it does |
| --- | --- |
| <a id="color-adjustment-picture-controls-enable-color-adjustment"></a>**Enable Color Adjustment** | **On** applies the picture controls below. **Off** bypasses those brightness and color adjustments. |
| <a id="color-adjustment-picture-controls-brightness"></a>**Brightness** | Adds an offset to the picture’s signal values. This shifts dark and bright parts together; it is not a physical monitor-backlight control and not the same as HDR target brightness. |
| <a id="color-adjustment-picture-controls-contrast"></a>**Contrast** | Changes the separation of picture values. One is neutral; values above one increase contrast, while values below one flatten it. |
| <a id="color-adjustment-picture-controls-saturation"></a>**Saturation** | Scales color intensity. One preserves the source’s saturation, zero removes color, and larger values make colors more intense. |
| <a id="color-adjustment-picture-controls-gamma"></a>**Gamma** | Changes the tonal response between black and white, primarily altering how intermediate shades are distributed. One is neutral. |
| <a id="color-adjustment-picture-controls-hue-degrees"></a>**Hue (degrees)** | Rotates the color hue relationship. Zero preserves the original colors. |
| <a id="color-adjustment-picture-controls-temperature-k"></a>**Temperature (K)** | Moves the renderer’s white balance from warmer toward the unchanged reference. In this menu 6500 K preserves the original image; lower values apply a warmer appearance. |
