# FrankyRenderer Nightly

Development source and test builds for fixes awaiting user feedback.

- [Download nightly test builds](https://github.com/mryx007/FrankyRenderer-Nightly/releases/latest)

- [Stable release](https://github.com/mryx007/FrankyRenderer/releases/latest)
- [Report a bug](https://github.com/mryx007/FrankyRenderer/issues)

Please include the build ID and player version when reporting results.

## Translations

The settings menu is translated on [Weblate](https://hosted.weblate.org/projects/frankyrenderer/). Anyone can help there, no Git knowledge needed.
